# 1.2 — From one line to a useful draft

About 15 minutes. Uses the notes in **1.1**. You write the prompts; ChatGPT answers.

## Round 1 — The lazy prompt

Open a **new chat** — without this link and without the notes — and type:

```
Write an invitation for our autumn member event.
```

What did it invent? Date, place, speaker?

*Why a new chat? This chat already contains the notes. A new chat shows what happens when
ChatGPT has nothing to go on.*

## Round 2 — Brief it

Come back to this chat and type:

```
Use the event notes from file 1.1.
Write an invitation email for our members.
Subject line plus max 110 words, warm but professional.
Use only the facts in the notes. Don't mention the guest speaker.
```

The five parts of a good request: **context** (the notes), **task** (an invitation),
**format** (subject line, 110 words, tone), **example** (optional), **limits** (only these facts).

## Round 3 — Improve it

Pick one and type it in the same chat:

- `Shorter, and put the registration deadline in the first sentence.`
- `Warmer, but no exaggeration.`
- `Give me two alternative subject lines.`
- `Rewrite it for someone who has never been to one of our events.`

## Round 4 — Let it check itself

```
Check your last draft against the notes. List every fact that is missing, changed or
not in the notes. Then give a corrected version.
```

It can still miss something. Its check helps you; it does not replace yours.
