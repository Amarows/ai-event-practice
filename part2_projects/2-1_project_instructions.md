# 2.1 — Project instructions

A ChatGPT **Project** keeps instructions and files in one place. Every chat inside the Project
starts with them, so a recurring task takes one line instead of a page.

How the parts of a good request move into a Project:

| Part of the request | Where it goes |
|---|---|
| Format, limits, example — what never changes | **Instructions** (below) |
| Context — facts and reference material | **Files** (for example 2.2) |
| Task — what you want today | **A new chat in the Project**, one line |

## Paste this into the Project's instructions

```
You help the events team write invitation emails for our members.

Format: a subject line plus max 110 words, warm but professional.
Put the registration deadline in the first sentence.

Use only facts from the Project files or from my message.
If a fact is missing, say so — do not guess.
Never mention speakers who are not confirmed.
```

## Then try

- New chat: `Invitation for the autumn member event.`
- Another new chat: `Invitation for the winter networking evening.`

Same format, different facts, nothing retyped. Check each against **2.2**.
