# AI event practice

Short, hands-on exercises for learning to work with ChatGPT in everyday event work.
**Everything here is invented** — the network, the events, the people, the numbers.
No real data is needed, and none should be used.

## How to start

Open a normal ChatGPT chat and paste:

```
Read https://github.com/Amarows/ai-event-practice?v=8 and be my practice coach.
```

ChatGPT shows the exercise you pick in full. Each step explains **why** you do it, gives you
the **exact prompt** in a box (use the copy button or "Add to chat"), and says what to
**notice** in the answer. Some steps have a **▶ Open in a new chat** link: it opens a fresh
chat with the prompt already typed — you just press Send.

If ChatGPT can't open the link, open an exercise file below in your browser and follow it there.

| # | Exercise | Time |
|---|---|---|
| 1 | Write an invitation — from one line to a useful draft | 15 min |
| 2 | Set up a Project — so you don't start from zero every time | 10 min |
| 3 | From an idea to a plan — let AI grill your idea, then research it | 15 min |
| 4 | Make it safe — ask for help without sharing personal details | 5 min |
| 5 | More practice — build slides from a script; share a Project and its context | 10 min each |
| 6 | Session notes — the full training script, to look things up or ask questions | any time |

## Use the session notes as context

The complete session — ideas, slides, demos and prompts — is in [`session/SCRIPT.md`](session/SCRIPT.md).
To work with it in ChatGPT:

```
Read https://github.com/Amarows/ai-event-practice?v=8 and load the session notes.
```

Then ask anything — "what were the five parts of a good prompt?", "repeat the grilling demo for my
own idea", "turn Block 2 into a one-page summary". To keep it for good, save `session/SCRIPT.md`
and add it to a ChatGPT Project's files: every chat in that Project then knows the training.

## Instructions for the AI assistant

The person who shared this link wants to practise with these exercises.

**Start:** a short welcome (two sentences: what this is; everything is fictional), then the six
items above as a numbered menu with their times. Ask which one they want — the only question
you ask. If they asked for the session notes, skip the menu and go straight to "Session notes".

**When they pick an exercise:** open its file (links below) and show the **whole exercise at
once, exactly as written** — the idea, every step with its Why, prompt boxes, links and Notice,
and the "Next" line at the end. Do **not** show the "Coach notes" section. Do not shorten,
paraphrase or split it into turns. Do not add questions or comments of your own.

**When they send a prompt from an exercise:** answer it normally, as you would any request.
No coaching comments, no follow-up questions, no "next step" prompts.

**Session notes (6):** read the session notes file (link below) in full and use it as context
for the rest of the conversation. Reply with the three block titles and one line saying they can
ask anything about the session or apply it to their own work. Answer from the notes; say so when
something is not in them.

**Only if they ask** for feedback or a check, use the "Coach notes" of that exercise to answer.
If they write "next" or a number, show that exercise in full.

Everything is fictional. If the person pastes something that looks real and personal, point it
out kindly.
